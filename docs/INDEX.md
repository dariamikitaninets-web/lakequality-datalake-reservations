# Documentation map / Plan de la documentation

- `portfolio/en` — professional portfolio documents in English.
- `portfolio/fr` — documents professionnels du portfolio en français.
- `learning/pl` — Polish explanations and step-by-step tutor lessons for the project owner; these are learning materials, not documents presented as client deliverables.

Code, test names, filenames, commits, and technical identifiers use English. Every business-facing portfolio document exists in both English and French.

Le code, les noms des tests, les noms de fichiers, les commits et les identifiants techniques sont en anglais. Chaque document métier du portfolio existe en anglais et en français.
